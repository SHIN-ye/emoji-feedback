### FER2013 表情分类基准（2026-11-12）

摄像头用前述 20 秒实测验证真实采集和入库。分类模型另用 [FER2013 测试分片](https://huggingface.co/datasets/Jeneral/fer-2013) 评估。使用项目的 DeepFace 0.0.93 情绪权重，对已裁好的人脸转为 48×48 灰度并归一化，按数据集标签名映射模型输出。全量测试分片包含 7,178 张图片。此实验单独衡量分类，跳过人脸检测。

|指标|结果|
|---|---:|
|七类 Top-1 准确率|56.90%（4,084 / 7,178）|
|七类平均召回率|53.99%|
|置信度 ≥ 0.60 的覆盖率|84.19%（6,043 / 7,178）|
|保留样本的准确率|61.84%（3,737 / 6,043）|

分类型召回率：开心 77.51%、惊讶 71.72%、中性 57.75%、厌恶 45.05%、生气 43.95%、恐惧 41.11%、悲伤 40.82%。根据 [NXP 模型说明](https://github.com/NXP/eiq-model-zoo/blob/main/tasks/vision/classification/deepface-emotion/README.md)，预训练权重使用过 FER2013，因此这些分数用于同数据集基准复核，独立泛化与课堂环境准确率仍待测量。预测对应表情标注，不能据此判断真实心理状态。

复现：在 AI 环境安装 `pyarrow==23.0.1`，下载数据源的 Parquet 测试分片，然后运行 `python -m scripts.evaluate_fer2013 artifacts/fer2013/test.parquet --output artifacts/fer2013/result.json`。结果 JSON 包含混淆矩阵、数据文件 SHA-256 和逐类统计。数据与本地生成结果放在 Git 忽略的 artifacts 目录。
