## 答辩说明

系统采用浏览器客户端和独立 Python AI 服务，通过统一 REST API 访问后端。界面事件、数据访问与后端业务分别组织，后端按 Controller、Service、Repository 分层。

角色权限在服务端校验，学生只能查询本人数据，教师限定所授课程。AI 使用独立令牌和 event_id，重复提交保持幂等，冲突内容被拒绝。数据库约束与业务校验共同保证关联关系和字段有效性。

课堂看板采用可见页面五秒轮询。统计参与人数按主动反馈学生去重，匿名 AI 记录只计入记录数量。当前模型完成公开数据集分类评测，真实教室多人远距离效果需后续验证。

现场启动时应使用当前有效课堂，确认名单安排已生效。全新环境按部署手册初始化，记录随机演示密码。成员职责见团队分工与贡献度表。
