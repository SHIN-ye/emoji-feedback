# 最终提交材料说明

依据实验指导书及线上提交通知，最终材料按以下四部分整理。实验报告与结题报告合并为《实验与结题报告》，同时提供可编辑 Word 和便于阅读的 PDF。

|目录|内容|
|---|---|
|01源码|完整仓库源码快照，包括前后端、AI 服务、测试、脚本、依赖及部署配置|
|02演示视频|系统演示 MP4，约 6 分 33 秒，含业务操作和 AI 验证说明|
|03项目文档|计划、需求与设计、测试报告、部署与用户手册、执行记录、贡献表、OpenAPI、SQL、实机截图及验证证据|
|04结题报告|实验与结题报告 Word、PDF|

源码快照保留仓库文档，便于按照 README 独立运行；另外三部分用于直接查看提交材料。运行数据库、账号密码文件、虚拟环境、模型权重、原始数据集和临时产物不随源码提交。新环境按部署手册安装依赖并初始化数据。

报告中的业务截图来自本地服务实际运行。AI 证据分别记录电脑摄像头短时采集、推理与入库测试，以及 FER2013 测试分片评测。当前没有教室摄像头及真实课堂验证条件，报告与视频均明确这一范围。

## 提交前填写与检查

1. 在报告封面填写班级、组号、成员；如修改 Word，请同步导出 PDF。
2. 按实际情况填写《团队分工与贡献度表》，补充姓名、学号、职责、贡献比例和签字。
3. 将文件夹名称中的“待填写组号”替换为实际组号。
4. 检查视频播放、报告排版和源码文件，确认后自行压缩为 `SE-EmojiChecker-组号-最终提交.zip`，按课程平台要求上传。
